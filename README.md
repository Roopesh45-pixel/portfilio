## 📊 Featured Projects

### 1. Hybrid Stock Price Prediction System
*Python · ARIMA · LSTM · GRU · Random Forest · SVM · FastAPI · Power BI*

An end-to-end forecasting system combining classical time-series models with deep
learning to predict stock price movement, then stress-tested through a reinforcement
learning trading simulation.

- Built and compared 5 predictive models (ARIMA, LSTM, GRU, Random Forest, SVM)
- Engineered SMA, RSI and MACD technical indicators as model features
- Built a reinforcement learning trading environment using OpenAI Gym —
  **achieved a 24.7% simulated return, outperforming a Buy & Hold benchmark**
- Served predictions via a FastAPI backend and visualised results in an interactive
  **Power BI dashboard** (actual-vs-predicted charts, technical indicator views, model comparison slicers)
- Evaluated performance using RMSE, MSE and R²

### 2. NHS A&E Demand and Emergency Admissions Performance Dashboard
*Power BI · Power Query (M) · DAX*

An interactive Power BI dashboard analysing multi-year NHS A&E attendance and
emergency admissions data to surface regional demand and operational pressure.

- Analysed **26.9M+ attendances** and **6.45M+ emergency admissions** across NHS
  England regions — overall admission rate of **23.9%**
- Built Power Query (M) transformations to clean and reshape multi-year data
- Authored DAX measures: Admission Rate %, Over-4-Hour Wait Rate, Month-on-Month
  Attendance Change
- Designed a KPI-card + trend + regional-comparison layout with slicers for Year,
  Month, Parent Organisation and Organisation, using a custom branded theme
- **Key insight:** NHS England Midlands = highest demand; NHS England South West =
  highest admission rate; March 2026 = busiest month
